# Python Object-Oriented Programming (OOP)

## 📌 Overview

This project demonstrates the fundamental concepts of **Object-Oriented Programming (OOP) in Python** through simple and practical examples.

The project covers:

- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Modules
- Static Methods
- Procedural Programming vs Object-Oriented Programming

---

## 🧠 Concepts Covered

### 1. Classes and Objects

Demonstrates the basics of creating and using classes and objects in Python.

- Classes
- Objects
- Attributes
- Methods
- Constructors
- Instance variables

---

### 2. Encapsulation

Encapsulation is demonstrated by restricting direct access to data and providing controlled access through methods.

Topics covered:

- Private attributes
- Getter methods
- Setter methods
- Data hiding

---

### 3. Inheritance

The project demonstrates different types of inheritance available in Python.

- **Single Inheritance**
- **Multilevel Inheritance**
- **Multiple Inheritance**
- **Hierarchical Inheritance**
- **Diamond Inheritance**

Inheritance allows a child class to reuse and extend the functionality of a parent class.

---

### 4. Polymorphism

Polymorphism allows the same interface or method to behave differently depending on the object.

The project demonstrates:

- Method Overloading
- Operator Overloading
- Method Overriding

Python magic methods are also used to demonstrate operator overloading.

---

### 5. Abstraction

Abstraction is implemented using Python's built-in `abc` module.

Topics covered:

- Abstract classes
- Abstract methods
- `ABC`
- `@abstractmethod`

Abstraction helps hide implementation details and expose only the required functionality.

---

### 6. Modules

The project demonstrates how Python modules can be created and reused.

Topics covered:

- Creating custom modules
- Importing modules
- Accessing functions from modules
- Accessing classes from modules

---

### 7. Static Methods

The project demonstrates the use of the `@staticmethod` decorator.

Static methods can be called directly using the class without creating an object.

---

### 8. Procedural Programming vs OOP

The project compares **Procedural Programming** and **Object-Oriented Programming** using an employee task-management example.

The comparison demonstrates how OOP provides:

- Better code organization
- Reusability
- Encapsulation
- Maintainability
- Separation of responsibilities

---
